# MASA – Memory and Attention Support Application

## Overview

MASA (Memory and Attention Support Application) is a proposed mobile application framework developed as part of a Human-Computer Interaction (HCI) research project.

The project explores how artificial intelligence, accessibility-focused interface design and cognitive training techniques can be combined to support individuals experiencing memory and attention difficulties.

## Proposed Features

- **Smart Reminder System:** Personalised reminders delivered at suitable times based on individual behavioural patterns.
- **Adaptive Focus Timer:** Customisable focus sessions designed to support attention regulation and productivity.
- **Cognitive Training Exercises:** Gamified exercises targeting memory, working memory and sustained attention.
- **AI Scheduling Assistant:** Personalised scheduling that adapts to individual routines and behavioural patterns.

## Design Principles

The proposed MASA framework incorporates several Human-Computer Interaction principles:

- Minimalist interface design to reduce cognitive overload.
- Accessible colour contrast and clear visual cues.
- Predictable navigation and simplified interactions.
- Personalisation based on individual user behaviour.
- Privacy-conscious AI processing using a combination of on-device and cloud computation.

## Research Areas

The project explores:

- Human-Computer Interaction (HCI)
- Cognitive rehabilitation technologies
- Digital interventions for ADHD
- Artificial Intelligence and personalisation
- Accessible and user-centred interface design
- Privacy considerations in AI-powered applications

## Project Scope

This project focuses on academic research, literature review and the development of a proposed application design framework.

The MASA framework is a conceptual proposal and has not yet been implemented as a functional mobile application.
